# Klin

**Klin** is a language made for low-level use with "easy-to-read code" (in a sense lol). This github include a documentaton and the code of the compiler. \
I use **[FASM](https://flatassembler.net/)** to compile the generated assembly code.\
I designed Klin in the hope of using it for a future kernel project.


[Read Documentation](docs/)
/!\ The documentation was written with the help of AI; I reviewed it, but it was written by AI.


The project is separated into 2 folders:

- `KlinLanguage`: The compiler itself
- `VirtualKlin`: The CLI app that runs the compiler

> *Project currently in design and early development phase.*
